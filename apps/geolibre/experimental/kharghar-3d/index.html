Height ranking data sources (static)
Merged candidate footprints: Google Open Buildings v3; Microsoft Global ML Building Footprints (2026-08-13); Overture Maps Buildings (2026-07-22).
Height values used in the fused layer: Overture published building height where present; DLR WSF3D v02 90 m area-average raster sampled at the footprint centroid.
Registered but not used in the current height score: Google Open Buildings Temporal (2016-2023) and DLR WSF3D area/fraction/volume morphology fields.
Context only, not merged into the height score: OpenStreetMap/OpenFreeMap, Sentinel-2 cloudless imagery, and Esri imagery.
